# COCOMA - Coordination de satellites

Projet réalisé dans le cadre du master AI2D à Sorbonne Université. Il étudie l'allocation de tâches d'observation à une constellation de satellites en respectant les créneaux temporels, les temps de transition et les portions d'orbite exclusives, afin de maximiser la récompense totale. Le projet s'inspire de l'article *Auction-based and Distributed Optimization Approaches for Scheduling Observations in Satellite Constellations with Exclusive Orbit Portions*, qui compare les enchères et l'optimisation distribuée pour coordonner plusieurs agents chargés de planifier des observations.
